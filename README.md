# RCC Calidad

Reporte de Codificación y Sellado (v1.21). App web instalable (PWA) para registrar fotos por máquina, generar el reporte PDF y enviarlo a Google Drive.

- Abrir: https://rafaelalejandrotorres100.github.io/rcc-calidad/
- Para publicar una actualización: reemplazar `index.html` y cambiar el nombre de la caché en `sw.js` (por ejemplo `rcc-v1.21` → `rcc-v1.22`).
